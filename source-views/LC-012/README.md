# LC-EXP-012 — Contested Claim Standing and Conditional Compositional Reassessment

Executable successor to **LC-EXP-011**, generated by sequential application of the supplied Lens Removal and Lens Shift v0.1.4 materials to LexiFORM's contested-claims research question.

## Reproduce

Python **3.10+** and standard library only; no cloud access, model download, training, or API keys.

```sh
python verify_manifest.py
python run_all.py
python benchmark.py
```

`run_all.py` runs **26 executable test groups**, including **512 generated expression structures**, **128 seeded claim-graph scenarios**, and **32 shuffled-order comparisons**, in addition to the targeted fixtures. The scripts write **mutable** `results/*_latest.json` files, intentionally excluded from the frozen manifest; original results are preserved as `results/*_observed.json`.

## Research target

Test meaning-preserving treatment of competing, conditional and cyclic `CORRECTS`, `SUPERSEDES`, `DISPUTES` and `ADDS_CONTEXT` relationships. Do not assert latest-claim priority. Keep claim, relation, admission, evidence, interpretation and historical reassessment distinct. Validate complete audit projections across list-form lexiconic, conventional typed AST, and limited independently coded semantic-oracle paths.

This experiment uses **declared synthetic semantics** and a Dung-style grounded argumentation policy. Passing means the implementations conform to that declared policy on the executed cases, not that they have discovered or authenticated meaning.

## Notable five-state episode

Original `T`; later opposing claim `U`; admitted correction `F`; counter-correction `T`; correction cycle `U`. Each snapshot and its evidence remain separately referencable. Context, reviewer permissions and conditional guards constrain which links can affect standing.

- `tests/`: targeted and seeded negative/null/generalization experiments.
- `results/`: independent summary, observed tests/benchmark and preserved receipts.

The lexicon and typed control implement equivalent formal argumentation rules. A difference in a single-environment Python benchmark cannot establish a **lexiconic-language** advantage. Independent semantic discovery, physical fact verification, authenticated review authority, externally independent decipherability and general reasoning superiority remain open.
